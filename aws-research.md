# AWS Research

## Brief Overview

Amazon Web Services (AWS) is an cloud computing platform provided by Amazon. It offers on-demand computing, storage, databases, networking, security, analytics, artificial intelligence, and many other services. AWS allows organizations to build and operate  the applications without having to purchase and maintain their own physical infrastructure.

## Global Infrastructure

AWS operates a large global infrastructure consisting of **Regions, Availability Zones, and edge locations**. AWS Regions are separate geographic areas, while a Availability Zones are isolated locations within a Region that help applications achieve higher availability and fault tolerance.

This global infrastructure allows organizations to deploy applications closer to their customers and design systems that can continue operating even when an individual resources experience failures.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services. Users can create resources, configure services, monitor applications, manage security settings, and control cloud resources through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable virtual servers in the cloud. Organizations can use EC2 to host websites, applications, APIs, and other workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve files and data. It can be used for backups, application data, media files, and data archives.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows organizations to create logically isolated networks within AWS. It provides control over IP addresses, subnets, routing, and network security.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources. It allows administrators to manage users, roles, permissions, and policies.

## Three Advantages

1. **Wide range of services** – AWS provides a large selection of cloud services for computing, storage, networking, databases, security, analytics, and AI.
2. **Global infrastructure** – AWS provides infrastructure across many geographic regions, allowing organizations to deploy applications globally.
3. **Scalability** – AWS resources can be increased or decreased according to workload requirements, helping organizations handle changing demand.

Typical Enterprise Use Cases

AWS is commonly used for:

* Web and mobile application hosting
* Enterprise application migration
* Backup and disaster recovery
* Data analytics
* Artificial intelligence and machine learning
* E-commerce applications
* Content delivery
* Internet of Things (IoT)
